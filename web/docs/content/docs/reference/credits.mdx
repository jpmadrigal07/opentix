## The Name

**Opentix** = **Open** + **Tickets**. Git-native ticket management that lives where your code lives — open source, open format, open workflow.

## Credits

- **John Patrick Madrigal** ([GitHub](https://github.com/jp.madrigal07)) — Creator and maintainer

## Contributing

Opentix is open source and welcomes contributions. If you would like to get involved:

- **GitHub**: [jpmadrigal07/opentix](https://github.com/jpmadrigal07/opentix)
- **Issues**: [Report a bug or request a feature](https://github.com/jpmadrigal07/opentix/issues)

See the [development setup guide](/docs/contributing/development-setup) to get started.
